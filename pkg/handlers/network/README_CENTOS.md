# CentOS 7.2-7.9 专用网络处理器

## 概述

本文档描述了为 CentOS 7.2-7.9 系统专门设计的网络配置处理器实现。该实现遵循方案A（操作系统特定的网络管理器实现），为 CentOS 7.x 系统提供了优化的网络配置管理。

## 架构设计

### 核心组件

1. **CentOSNetworkHandler** - CentOS 专用网络处理器
2. **CentOSNetworkManager** - CentOS 专用 NetworkManager 实现
3. **CentOSIfupdown** - CentOS 专用传统网络脚本实现

### 文件结构

```
pkg/handlers/network/
├── centos.go                    # CentOS 专用网络处理器
├── centos_networkmanager.go     # CentOS 专用 NetworkManager 实现
├── centos_ifupdown.go          # CentOS 专用传统网络脚本实现
├── centos_nmconnection.tpl     # NetworkManager 配置模板
├── centos_ifcfg.tpl           # ifcfg 配置模板
└── init.go                     # 处理器注册
```

## 网络管理器

### 1. CentOS NetworkManager

**优先级**: 最高

**特性**:
- 专为 CentOS 7.x 优化的 NetworkManager 实现
- 使用 `centos_nmconnection.tpl` 模板
- 支持版本兼容性检查
- 增强的连接激活逻辑（更长的超时时间）
- 网络稳定性等待机制

**检测方式**:
```bash
systemctl is-active NetworkManager
nmcli --version  # 版本兼容性检查
```

**配置文件路径**:
```
/etc/NetworkManager/system-connections/nix-operator-{interface}.nmconnection
```

### 2. CentOS 传统网络脚本

**优先级**: 备选

**特性**:
- 专为 CentOS 7.x 设计的传统网络脚本实现
- 使用 `centos_ifcfg.tpl` 模板
- 支持多种网络重启方法
- 自动更新 `/etc/resolv.conf`
- 智能检测其他网络管理器冲突

**检测方式**:
```bash
which ifup && which ifdown
ls /etc/sysconfig/network-scripts/
systemctl is-enabled network
```

**配置文件路径**:
```
/etc/sysconfig/network-scripts/ifcfg-{interface}
/etc/resolv.conf  # DNS 配置
```

## 配置模板

### NetworkManager 模板 (centos_nmconnection.tpl)

```ini
[connection]
id=nix-operator-{{.Name}}
type=ethernet
interface-name={{.Name}}
autoconnect=true
autoconnect-priority=100

[ethernet]

[ipv4]
{{- if .IPv4Address}}
method=manual
addresses={{.IPv4Address}}
{{- if .IPv4Gateway}}
gateway={{.IPv4Gateway}}
{{- end}}
{{- if .Nameservers}}
dns={{range $i, $ns := .Nameservers}}{{if $i}};{{end}}{{$ns}}{{end}}
{{- end}}
{{- else}}
method=auto
{{- end}}
```

### ifcfg 模板 (centos_ifcfg.tpl)

```bash
# Generated by nix-operator
TYPE=Ethernet
BOOTPROTO={{if .IPv4Address}}static{{else}}dhcp{{end}}
DEVICE={{.Name}}
ONBOOT=yes
{{- if .IPv4Address}}
IPADDR={{.IPv4Address}}
{{- if .IPv4Gateway}}
GATEWAY={{.IPv4Gateway}}
{{- end}}
{{- if .Nameservers}}
DNS1={{index .Nameservers 0}}
{{- end}}
{{- end}}
```

## 故障排除

### 常见问题

1. **NetworkManager 服务未运行**
   ```bash
   systemctl start NetworkManager
   systemctl enable NetworkManager
   ```

2. **传统网络脚本冲突**
   ```bash
   systemctl stop NetworkManager
   systemctl disable NetworkManager
   systemctl enable network
   ```

3. **接口名称不标准**
   - 检查 `ip link show` 输出
   - 确认接口名称符合 CentOS 7.x 命名规范

4. **权限问题**
   ```bash
   # 确保配置文件权限正确
   chmod 600 /etc/NetworkManager/system-connections/nix-operator-*
   chmod 644 /etc/sysconfig/network-scripts/ifcfg-*
   ```

### 调试命令

```bash
# 检查 NetworkManager 状态
systemctl status NetworkManager
nmcli connection show
nmcli device status

# 检查传统网络脚本
systemctl status network
ls -la /etc/sysconfig/network-scripts/ifcfg-*

# 检查网络接口
ip addr show
ip route show
```

## 性能考虑

- **模板缓存**: 模板在首次使用时解析并缓存
- **原子写入**: 使用 `utils.AtomicWriteFile` 确保配置文件完整性
- **超时控制**: 所有外部命令都有合理的超时设置
- **错误恢复**: 支持多种网络重载方法的回退机制

## 安全考虑

- **文件权限**: NetworkManager 配置文件设置为 600 权限
- **输入验证**: 严格验证接口名称和网络配置
- **命令注入防护**: 使用 `exec.CommandContext` 避免命令注入
- **原子操作**: 配置文件更新使用原子写入操作
